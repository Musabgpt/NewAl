# NewAl for VS Code

NewAl inside VS Code: a coding agent that runs on your own computer (Qwen3.6, no cloud, free).

- **▶ اشتغل هلق على هالمشروع** — NewAl works on the open folder: reads, edits, runs the project's tests and fixes until
  they pass. Its steps stream into the *NewAl* output panel; risky commands ask first; one click undoes everything.
- **＋ مهمة بالخلفية** — like Codex Cloud: the task runs on a separate copy (a git worktree), and when it is done its
  changed files appear under the task: click one to see it in VS Code's diff view, then apply, discard, or open a
  pull request.

Needs the NewAl app running on the same computer (it installs this extension with one click).
