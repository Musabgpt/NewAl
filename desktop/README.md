# NewAl لويندوز

مساعد محلي مجاني على جهازك: يبرمج ويجرّب الكود ويصلحه، يبحث بالنت، يشغّل PowerShell، يتذكر مشروعك،
ومربوط بـ GitHub وGitLab وGoogle Drive وKaggle وVS Code.

الهدف البعيد: **MusabAI**، نظام شخصي كامل (نماذج + وكلاء + ذاكرة + أدوات + تحقق بالأدلة + تقييم مستمر)، النموذج فيه
جزء بيتبدّل والباقي بيضل. الرؤية ووين وصلنا بكل بند: [docs/musabai.md](../docs/musabai.md).

## التثبيت
1. من GitHub ← Actions ← «Build NewAl for Windows» ← آخر تشغيل أخضر ← نزّل `NewAl-Windows-Setup`.
2. فك الضغط وشغّل `NewAl-Setup.exe` (لا يحتاج صلاحيات مدير). لو ظهر تحذير SmartScreen: «مزيد من المعلومات» ← «تشغيل على أي حال».
3. افتح NewAl ← 🧠 النماذج ← «تنزيل الكل» (~17.3 GB، يكمل من حيث توقف لو انقطع النت).
4. 🧩 الإضافات ← «⚡ جهّز كل شي»: يثبّت ويربط كل الإضافات تحت بضغطة وحدة.

## 💻 NewAl Code: وكيل برمجة متل Codex وClaude Code
برنامج البرمجة الجديد جوّا NewAl: زر «💻 NewAl Code» بالقائمة، أو `NewAl\code\NewAlCode.exe`، أو
`python -m newal_code app` من مجلد `desktop`. التفاصيل كلها: [docs/newal-code.md](../docs/newal-code.md).
- **بيشتغل متل Claude Code وCodex:** بيقرأ ويبحث ويعدّل ويشغّل الأوامر والاختبارات لحتى تخلص المهمة، وبعدين
  الكمبيوتر بيتأكد باختبارات المشروع. فيه كل شي تعودت عليه هناك: أوضاع الصلاحيات (قراءة بس، اسأل، وكيل، وصول
  كامل)، AGENTS.md وCLAUDE.md، المهارات (SKILL.md)، الأوامر الخاصة (/)، الـ hooks، MCP، الإضافات (plugins بنفس
  شكل Claude Code)، الوكلاء الفرعيين، دفاتر Jupyter، `/goal`، `/plan`، `/review`، `/compact`، `/undo`، `/add-dir`،
  محادثات بتكمل بعدين، worktree لكل محادثة، Commit وPush وPull Request من التطبيق، وصندوق معزول للأوامر على
  ويندوز وماك ولينكس: الأمر بيقرأ ويشغّل أي شي، بس ما بيكتب إلا جوّا المشروع والمجلدات اللي ضفتها.
- **أي نموذج أو أكتر من نموذج:** GGUF على جهازك (llama.cpp تبع NewAl ونفس النماذج اللي نزّلتها)، أو أي API
  متوافق مع OpenAI (Ollama، LM Studio، OpenRouter، OpenAI، DeepSeek، Gemini…)، أو Anthropic. وبتقدر تعطي أدوار
  لنماذج مختلفة (السريع، المراجِع، المخطِّط).
- **على أجهزة 8 لـ 16 GB:** بيقرأ الـ RAM وملف النموذج نفسه، وبيحسب كل شي بيحجزه llama.cpp (الأوزان، الـ KV cache،
  حالة الطبقات المتكررة ونسخها، بفرات الحساب)، وبيختار أطول سياق بيساعه الجهاز وبيترك حصة لويندوز والمتصفح.
  8 GB ← Qwen3.5 4B، و12 و16 GB ← Qwen3.5 9B (الاتنين مع رؤوس MTP اللي بتسرّع الكتابة). جرّبنا كل حجم على جهاز
  محاكى (حد ذاكرة بحجم الجهاز، وبرنامج تاني ماسك حصة ويندوز والبرامج): على 8 GB خلّص اختبار السرعة كله صح 6 من 6 بـ
  495 ثانية والنموذج مع البرنامج ما تعدّوا 4.9 GB، وعلى 12 GB خلّصه 6 من 6 بـ 592 ثانية، وولا مرة انقتل شي. أما عقل
  NewAl الحالي (Qwen3.6 35B-A3B، ‏15.35 GB) فما بيساعه ولا واحد من هالأجهزة.
- **أسرع بكتير:** نفس الجهاز ونفس ملف النموذج (Qwen3.5 4B) ونفس المهام الست (إصلاح خطأ، إضافة خيار، كتابة دالة،
  إعادة تسمية بكل المشروع، سؤال عن الكود، إصلاح crash) واختبارات مخفية بتتأكد من الشغل: NewAl الحالي (وضع المشروع)
  خلّصها بـ 2865 ثانية وصحّ منها 4، وNewAl Code صار يخلّصها بـ 488 ثانية وصحّوا الست كلهم: **أسرع 5.9 مرات**
  (83% وقت أقل). ومع ملف MTP عند الاتنين: 2227 ثانية مقابل 341 و390، يعني أسرع 6.1 مرات (84% وقت أقل). السر إنه
  بيكتب أقل بكتير (3 آلاف توكن بدل 11 ألف) وبيعمل 21-23 طلب للنموذج بدل 80: بيجيب الملفات اللي بتلزم المهمة من أول
  رسالة، وبيعدّل سطور قليلة، واختبارات المشروع بتشتغل لحالها مع كل تعديل ونتيجتها بتوصل للنموذج بنفس الخطوة. إذا
  قصدك بـ «90%» عُشر الوقت، لسا ما وصلنا (84%). الأرقام كلها بـ [docs/newal-code.md](../docs/newal-code.md#speed).
- **واجهة متل تطبيق Codex:** المحادثات مجمّعة حسب المشروع على اليسار، الشغل بخطوات مختصرة («Explored» /
  «Ran» / «Edited» مع الـ diff)، لوحة Review للتغييرات مع Commit، طرفية، واختيار النموذج والتفكير والصلاحيات تحت
  مربع الكتابة. وكمان واجهة بالطرفية متل Codex CLI (`python -m newal_code`).
- **الصندوق المعزول:** على لينكس Landlock، وعلى ماك Seatbelt (متل Codex)، وعلى ويندوز الأمر بيشتغل بمستوى «low
  integrity» (نفس اللي بتستعمله المتصفحات لصناديقها) وما بيقدر يكتب إلا بالمجلدات اللي انعلّمت إلها. Git Bash بيشتغل
  من نسخة إلها لحالها من ملفات Git (hard links ما بتاخد مساحة، وإذا ويندوز ما سمح فيها بتنعمل نسخة مرة وحدة، حوالي
  96 MB)، فبيمشي حتى لو عندك Git Bash تاني مفتوح وما بيشارك معه شي. وإذا الصندوق منع أمر، NewAl Code بيسألك إذا بدك
  تشغّله برّاه.
- **نسخ لويندوز ولينكس وماك:** `.github/workflows/newal-code.yml` بيبني Windows x64 وLinux x64 وmacOS (Apple silicon
  وIntel) مع llama.cpp جوّاها، وبيجرّب كل نسخة متل ما بيشغّلها المستخدم (الصندوق المعزول ونموذج GGUF حقيقي)، وبينشرها
  بـ pre-release اسمه `newal-code-b<N>` (ما بتصير «latest»، فتحديثات NewAl نفسه ما بتتأثر).
- **مهام سحابية (cloud tasks):** زر ☁ بالتطبيق أو `python -m newal_code cloud "المهمة"`: المهمة بتنبعت لـ GitHub Actions
  بمستودعك، الوكيل بيشتغل هناك بنموذج GGUF (بيتنزّل مرة وبينحفظ) أو بأي API، والنتيجة بترجعلك diff بتطبّقه عندك أو
  بتعمل منه Pull Request، وجهازك مسكّر عادي. جرّبناها فعلياً على هالمستودع: Qwen3.5 4B عمل الملف المطلوب بـ 79 ثانية.
- **تطبيق GitHub:** `python -m newal_code github install` بيضيف workflow لمستودعك: اكتب `@newal` بتعليق على issue أو
  pull request (بس لأصحاب المستودع وأعضائه والمتعاونين)، وهو بيجاوب، أو بيراجع الـ PR بتعليقات على السطور المتغيّرة، أو
  بيعمل التعديل: على فرع الـ PR، أو من الـ issue لفرع جديد مع Pull Request.
- **NewAl Code Lite لأندرويد (جوالات 2 لـ 4 GB):** APK فيه Python الرسمي لأندرويد وllama.cpp مبني للجوالات وNewAl Code
  نفسه، وكله بيشتغل عالجوال (بعد ما ينزل النموذج ما بيلزمه نت). 2 و3 GB ← Qwen3.5 0.8B، و4 GB ← Qwen3.5 2B، بوضع
  «lite»: محادثة وحدة، سياق لحد 16k، وبفرات أصغر. جرّبناه على محاكي جوال: على 3 GB الوكيل كتب `hello.py` وشغّله بـ
  25 ثانية وllama-server ما تعدّى 1023 MB، وعلى 2 GB عملها بـ 29 ثانية وllama-server ما تعدّى 770 MB وضل عالجوال
  809 MB فاضيين على الأقل. بيتنشر بـ pre-release اسمه `newal-code-lite-b<N>`.
- **إذن واحد لكل شي:** «Give full access» مرة وحدة (من شاشة الترحيب أو الإعدادات أو `newal-code access full`)، وبعدها
  المحادثات الجديدة بتشتغل بدون صندوق معزول وبدون ما تسألك، إلا الأوامر اللي بتمسح قرص أو مجلدك أو ويندوز، هاي دايماً
  مرفوضة. عالجوال نفس الكبسة بتمشيك على أذونات أندرويد وحدة ورا التانية (الإشعارات، الملفات، التحكم بالشاشة، Termux).
- **ويندوز:** أداة `powershell` للوكيل جنب Git Bash، ولوحة الطرفية فيها PowerShell أو Git Bash، و`newal-code install`
  بيحط `newal` بكل طرفية (PowerShell وcmd وGit Bash) و«Open with NewAl Code» بقائمة الكبسة اليمين بالمستكشف وملف تعريف
  بـ Windows Terminal، بدون صلاحيات مدير. وربط GitHub بياخد تسجيل دخولك الموجود (GitHub CLI أو Git Credential Manager)
  بدون ما تنسخ توكن.
- **الواجهة بالعربي:** من اليمين لليسار، لحالها إذا لغة الجهاز عربي (متل الجوال)، أو من الإعدادات ← Language ← العربية.
  كل رسالة بتاخد اتجاه نصها، والكود والطرفية بيضلوا من اليسار لليمين.
- **جوّا تطبيق الجوال كمان:**
  - **الصوت والمشاركة:** زر المايك بيكتب اللي بتحكيه (التعرّف على الكلام بلغة الجوال)، و«مشاركة» من أي تطبيق لـ NewAl
    Code بتفتح محادثة جديدة فيها النص والملفات.
  - **Gemini أو DeepSeek بكبسة زر** (ومعهم OpenAI وOpenRouter وAnthropic وGroq): انسخ مفتاحك واكبس اسم المزوّد، بيتصل
    فوراً. وإذا ما كان المفتاح منسوخ، بتفتح صفحة المفاتيح عندهم، وأول ما ترجع ومعك المفتاح منسوخ بيتصل لحاله، وبيختار
    أحدث وأسرع نموذج عندهم. بتلاقيها بـ Models ← «An API in one tap» أو آخر قائمة النماذج.
  - **التحكم بالجوال:** الوكيل بيفتح التطبيقات والإعدادات، بيضبط منبّه أو مؤقت، بيشغّل الضو، بيغيّر الصوت، بيبعت إشعار،
    وبيجهّز رسالة أو مكالمة (الإرسال والاتصال بإيدك). وإذا شغّلت «NewAl Code» بإعدادات إمكانية الوصول (This phone ←
    Screen control)، بيشوف الشاشة وبيكبس وبيكتب وبيمرّر وبيرجع لورا. على أندرويد 13 وأحدث إذا طلع المفتاح رمادي
    («إعداد محظور»): معلومات التطبيق ← ⋮ فوق ← «السماح بالإعدادات المحظورة»، وبعدين شغّله. بيسألك قبل كل حركة إلا إذا المحادثة
    full-auto، والنظر بس (الشاشة، التطبيقات، البطارية) ما بيسأل عنه.
  - **GitHub:** Settings ← GitHub ← «Connect GitHub» (انسخ token وبيتصل)، وزر ⬇ جنب Threads بيعرض مستودعاتك وبينزّل
    اللي بدك ياه كمشروع. والجوال ما فيه git، فالتطبيق جايب git تبعه (مبني على dulwich) بيطبع متل git وبيعمل نفس الـ
    commits. Commit وPush وPull Request بيشتغلوا من الجوال.
  - **Termux:** Settings ← This phone ← «Connect Termux» بينسخ أمر واحد وبيفتح Termux: الصقه واكبس Enter، وبيصير NewAl
    Code شغّال جوّا Termux (مع git والبايثون وكل باكجات Termux ومشاريعك هناك)، بنموذج الجوال نفسه أو بأي API، والتطبيق
    بيعرضه («Open the Termux workspace»).
  - **نماذج GGUF اللي عندك عالجوال:** Models ← «Your GGUF files»: اكبس «Let NewAl Code read the phone's files» وفعّل
    «السماح بإدارة كل الملفات»، وبتطلع ملفات GGUF اللي بـ Download وDocuments (وتنزيلات تيليغرام) كنماذج مع زر Use،
    وبتشتغل من مكانها بدون نسخ. أو «Pick a GGUF file…» لأي ملف، أو «Copy a GGUF into the app…» بينسخه جوّا التطبيق
    (للجوالات اللي ما بتسمح بكل الملفات متل Android Go).
  - **الشاشة على Android 15:** الصفحة صارت بين شريط الحالة وشريط التنقل (وفوق الكيبورد)، والقائمة الجانبية (الزر اللي
    فوق عالشمال) فيها New thread وModels وGitHub و«This phone» (Termux والتحكم بالشاشة وملفات الجوال) وSettings.
  - **النماذج الصغيرة أسرع:** نموذج الجوال بياخد أدوات أقل ووصف أقصر (نص البداية صار تقريباً النص)، والمحادثة بتنفتح
    وأنت عم تكتب أول رسالة فالنموذج بيحمّل وبيقرا بدايتها بنفس الوقت. وصار النموذج يعرف إنه عالجوال وبيستعمل أداة
    الجوال لفتح التطبيقات بدل ما يجيب صفحة الموقع.
  - **المكونات الإضافية بدون كتابة أوامر:** «Plugins & skills» بتنزّل plugin من رابط git أو owner/repo أو
    name@marketplace، وبتضيف سوق plugins (بصيغة Claude Code) وبتعرض اللي فيه مع زر Install، وكل plugin معه زر Remove.
  - **إضافات NewAl المدمجة:** أول قسم بصفحة «Plugins & skills»، بتنزل بضغطة وحدة بدون إنترنت، وكل وحدة فيها برنامج
    بيشتغل فوراً بدون النموذج (فبتشتغل حتى مع نموذج صغير أو بدون نموذج):
    - `system`: ‏`/sysinfo` (الجهاز والذاكرة والتخزين والبطارية والشبكة، وأي حجم نموذج GGUF بيساع بالذاكرة هلق)،
      ‏`/disk` (شو عم ياخد المساحة)، ‏`/clean` (بيعرض الكاش والملفات المؤقتة القديمة بأحجامها، و‏`/clean --yes` بيحذفها
      هي بس)، ‏`/ports` (مين عم يستعمل أي منفذ)، ‏`/programs` (بحث وتثبيت وتحديث برامج: winget على ويندوز، pkg على
      Termux، Homebrew، apt). بتشتغل على ويندوز وماك ولينكس والجوال وTermux، وبالعربي إذا الواجهة عربي.
    - `data`: ‏`/csv ملف [عمود] [عمود القيم]` بيحلل ملف CSV أو Excel أو JSON فوراً (عدد الصفوف، نوع كل عمود،
      الفراغات، الأدنى والأعلى والمتوسط والمجموع، الأكثر تكراراً)، وبيرسم مخطط SVG (مثلاً المبيعات حسب المنطقة). بيفهم
      ملفات Excel العربية (cp1256) والأرقام العربية.
    - `arabic`: ‏`/rtl` بيحوّل الموقع من اليسار لليمين: ‏`dir="rtl"` على الصفحة، وكل left/right بالـ CSS لخصائص منطقية
      (margin-inline-start، text-align: start...) بملفات CSS وstyle وJSX، بدون ما يلمس أسماء الكلاسات. بيعرض التغييرات
      أول، و‏`/rtl --apply` بيكتبها.
    - `starters`: ‏`/create python|web|node|flask|fastapi اسم` بيعمل مشروع جاهز بيشتغل فوراً (برنامج مش النموذج)،
      مع README واختبار بيشغّله ليتأكد إنه ناجح. و‏`--ar` بيعمله بالعربي من اليمين لليسار.
    - `guard`: حتى مع الصلاحية الكاملة، بيسألك قبل تعديل ملفات الأسرار (‎.env والمفاتيح) وقبل force push أو hard reset
      أو حذف فرع أو حذف قاعدة بيانات أو نشر حزمة، وقبل أي commit أو push رح ينشر مفتاح أو توكن. و‏`/secrets`
      بيدوّر على المفاتيح المسرّبة بالمشروع (GitHub وGoogle/Gemini وOpenAI/DeepSeek وAWS...).
    - بإضافة `system` كمان: ‏`/serve` بيفتح صفحات مجلد بالمتصفح (و‏`--lan` لتفتحها من الجوال على نفس الواي فاي).
    - `format-on-edit`: بعد كل تعديل بينسّق الملف بأداة المشروع (gofmt وrustfmt وdart دايماً، وruff/black وprettier
      وclang-format إذا المشروع مجهّز إلها).
    - ومن الطرفية: `newal-code plugin list` و`newal-code plugin install system@newal`.
  - **`/issues`:** بيعرض الـ issues المفتوحة بمستودع GitHub تبع المشروع، و‏`/issues 7` بيخلّي NewAl يشتغل على الـ issue
    رقم 7 (نصها وتعليقاتها) ويقترح commit بينتهي بـ "Fixes #7".
  - **`/sync`:** أمر واحد بيجيب تغييرات GitHub وبيرفع تغييراتك (pull ثم push) بحساب GitHub الموصول بـ NewAl Code، على
    الكمبيوتر وعالجوال. إذا في تعارض بيقلك بأي ملفات وكيف تكمّل أو ترجع. وgit تبع الجوال صار يعمل merge حقيقي لما يكون
    في تعديلات من الطرفين (قبل كان يفشل)، ومعه `git merge --continue` و`git merge --abort`.
  - **الأمان:** سيرفر NewAl Code ما بيرد إلا على اللي معه مفتاحه، لأنه أي تطبيق تاني عالجوال بيقدر يوصل لـ 127.0.0.1.

## 🩺 فحص شامل وتقرير
⚙ الإعدادات ← «🩺 فحص شامل»: بيجرّب الجهاز والبرنامج والنماذج وسرعة العقل (قراءة/كتابة بالكلمة بالثانية) وحلقة البرمجة
والعيون ووضع المشروع والنت والمتصفح، وبيكتب تقرير واحد (ومعه آخر سجلات المحرك إذا في فشل): «📋 نسخ التقرير» وابعته.
«⚡ فحص سريع» بثواني بدون تشغيل النماذج.

## ⬆ التحديث
كل بناء ناجح بينشر كـ Release على GitHub (`desktop-b<رقم>`، آخر 6 بس). NewAl بيشوف كل كم ساعة إذا في أحدث، وبيطلع شريط
«⬆ في نسخة جديدة» ← «حدّث هلق»: بينزّل المثبّت، بيسكّر حاله، بيتثبت بصمت، وبيرجع يفتح.

## البرمجة
Qwen3.6 يجيب توثيق المكتبات الحالي (إذا إضافة التوثيق مثبتة) ← يكتب الكود ← NewAl يشغّله (بعد موافقتك)
← Qwen3.6 يحكم على النتيجة ← إذا فشل يصلح على أساس الخطأ (ولو الخطأ من استخدام مكتبة غلط يرجع للتوثيق)
← وهكذا حتى 5 محاولات (من الإعدادات). بتشوف بس النسخة الأخيرة، والمحاولات بصندوق مطوي.

## ⚡ السرعة
على معالج لابتوب Qwen3.6 بيقرأ ~24 كلمة/ث وبيكتب 5–6 (مقاس على i7-8650U بـ `tools/bench_brain.py`)، فأهم شي إنه
**ما يعيد قراءة شي قرأه**. القياسات هون بمسار NewAl الحقيقي:
- **أول جواب فوري:** أول ما يفتح NewAl بيتحمّل العقل وبيقرأ تعليماته وقائمة أدواته بالخلفية. أول كلمة لأول سؤال: 0.8 ث بدل 118 ث.
- **بداية ثابتة لكل الطلبات:** المحادثة والأدوات والكود والتحليل بيشاركوا نفس التعليمات ونفس قائمة الأدوات، فالتنقّل بينهم ما بيعيد
  قراءة المحادثة. الأسئلة القديمة بتنبعت متل ما انبعتت أول مرة، والأجوبة القديمة بتنكتب متل ما كتبها النموذج (`preserve_thinking`).
  تحققنا بـ llama.cpp نفسه: كل طلب جديد بيبلّش بالطلب اللي قبله كامل، يعني بيقرأ بس سؤالك الجديد.
- **المحادثات الطويلة:** نافذة التاريخ بتتحرك بقفزات كبيرة، مو رسالة بكل سؤال.
- **MTP (التوليد المسرّع):** العقل بيخمّن 3 كلمات جاية وبيتحقق منهم دفعة وحدة، بس لما يكون متأكد ≥60%.
  قسناه على Qwen3.6 نفسه على معالج 4 أنوية AVX2: الكود 6.1 ← 9.7 كلمة/ث، والعربي 6.3 ← 7.4. بيشتغل مع 👁 العيون.
  على لابتوب i7-8650U الربح أقل: الكود 5.1 ← 5.7–5.9، والعربي ما تغيّر (~5). وعدد الأنوية للكتابة (3 أو 4 أو 6)
  فرقه أصغر من الفرق بين تشغيلتين؛ القراءة بـ 8 خيوط أسرع من 4 (23.6 مقابل 21.1).
  نسخة العقل القديمة بتضل شغالة، و«⚡ نزّل نسخة العقل الأسرع» بترقّيها بضغطة.
- **استدعاءات أقل:**
  - كلمات البحث بتنقص من سؤالك بلا نموذج.
  - صفحتين بس للجواب.
  - اختبارات الكود (assert) إذا نجحت بتغني عن «الحَكَم».
  - توثيق المكتبات بس عند خطأ بالمكتبة.
  - الدروس بتنكتب لما ما حدا مستني جواب.
  - وضع المشروع بيفكّر بأول خطوة وبعد الفشل بس.
  - وضع 💭 بيرجّع كل التدقيقات.
  - الدردشة العادية جواب واحد بلا جولة أدوات، إلا إذا طلبت شي ينعمل أو ينحسب (افتح، ثبّت، احسب…).
  - خطة الهدف والتحقق منه بيضلّوا بنفس المحادثة، فـ llama.cpp بيكمّل من وين وقف بدل ما يعيد قراءة الأدلة كل مرة.
  - مخرجات الأدوات بتوصله مختصرة: بلا ألوان ولا أشرطة تقدّم ولا أسطر مكررة، وأول وآخر المخرجات (وين الخطأ أو النتيجة).
- **⚡ السرعة (بالقائمة):**
  - كل استدعاء: شو قرأ وشو لقى جاهز وشو كتب، وبأي سرعة.
  - تنبيه البطارية وموفّر الطاقة، وزر «أداء عالي».

- **⏰ مهام مجدولة**: «كل يوم الساعة 8 لخصلي أخبار الذكاء الاصطناعي» — من اللوحة أو بالمحادثة. كل مرة بتنعمل

## ✅ أدوات حقيقية، بلا نتائج وهمية

- **كل أداة بتنفذ فعلاً**: قبل أي استدعاء بيتأكد إنو الأداة موجودة ووسائطها صح (اسم غلط متل `powershell` أو
  `vscode_open` بيتحول للأداة الحقيقية، وأداة مو موجودة بترجع رسالة واضحة بدل نتيجة مخترعة).
- **ما بيقول «عملت» إلا إذا أداة عملت**: إذا الجواب قال «أنشأت/شغّلت/فتحت/ثبّت/نزّلت/جدولت» وما في أداة نفذت هالشي،
  بيرجع بيعمله فعلاً أو بيعترف إنو ما انعمل. (أكبر سبب لفشل الوكلاء هو «النجاح الكاذب»: 44–76% من الأخطاء
  [arXiv 2606.09863](https://arxiv.org/abs/2606.09863).)
- **🎯 الهدف ما بيخلص إلا بدليل**: الملفات اللي بيذكرها لازم تكون موجودة فعلاً على الجهاز، ونتائج الأدوات لازم
  تثبت النتيجة ([Evidence-Carrying Termination](https://arxiv.org/pdf/2608.23623)). إذا فشل التحقق ما بينحسب «تم»،
  وإذا خلصت الخطوات بيقلك بالضبط شو الناقص بدل ما يعطيك نص حل.
- **cmd وPowerShell وWSL**: `run_command` مع `shell` = powershell أو cmd (بـ UTF-8 حتى الأسماء العربية تطلع صح) أو
  wsl، ومهلة لحد 30 دقيقة للتثبيت والبناء.
- **VS Code كأداة كاملة**: فتح، الانتقال لسطر، مقارنة ملفين، تثبيت وعرض الإضافات.
- **القراءات بالتوازي**: عدة بحثات/صفحات/ملفات بنفس الخطوة بتنقرى سوا.
- **مخرجات الأوامر مباشرة**: شو عم يطبع الأمر بيبيّن بالمحادثة وهو شغال، مو بس بالآخر.
- **📘 طرق الإنجاز**: الهدف يلي بيخلص وبيتأكد منه بالأدلة بيحفظ خطواته الناجحة. هدف مشابه بعدين بيبدأ منها (وبيرجع
  يتحقق من كل شي). اللي ما تأكد منه ما بينحفظ.
- **🧾 سجل الأدوات**: كل أداة شغّلها أو رفضتها، مع وقتها ونتيجتها، بـ «🗂 الذاكرة» وبملف `audit.jsonl`. التوكنات وكلمات السر مخفية.
- **Kaggle بضغطة**: «🔗 الربط» ← «ربط Kaggle بضغطة». إذا عندك مفتاح على الجهاز بيستخدمه فوراً، وإلا بيفتح صفحة
  Kaggle وبياخد المفتاح لحاله أول ما تعمله (kaggle.json أو توكن KGAT_) وبيتأكد بطلب حقيقي.
- **أخف**: عقل واحد بالذاكرة (الموجّه الصغير ما بينحمل)، والأوضاع صارت: تلقائي، هدف، مشروع، بحث معمّق، صورة.

## 🧑‍💻 وضع المشروع (متل Codex وClaude Code)
بتفتح مجلد مشروعك (📂 فوق)، بتختار 🧑‍💻 مشروع، وبتكتب المهمة. Qwen3.6 بيشتغل جوّا المجلد بأدواته:
`list_files`، `search` (متل grep: بدون حساسية للأحرف، مع أسطر حوالين النتيجة، أو أسماء الملفات بس)، `read_file`،
`edit_file` (تعديل دقيق لقطعة من الملف، أو `replace_all` لإعادة تسمية)، `write_file`، `run` (أوامر واختبارات، أو
`background` للأوامر الطويلة مع `job_output`)، `todo` (قائمة مهام بتشوفها عم تتحدّث)، `diff`.
بيشوف **خريطة الكود** (كل الدوال والكلاسات بكل ملف) قبل ما يبلش.

**بيشتغل بنفس طريقة Claude Code اللي صلّح NewAl على هاللابتوب:**
- بيدوّر عالأدلة قبل ما يغيّر: بيقرأ الكود والأخطاء والسجلات، حتى لو السجلات برّا المشروع (قراءة بس).
- بيكتب سطر قبل كل خطوة، وبيعيد إنتاج الخلل قبل ما يصلّحه.
- بيعدّل بدقة، وبيضيف اختبار للخلل، وبيشغّل الاختبارات لحتى تنجح.
- بالآخر بيكتب تقرير: شو غيّر، كيف تأكد، وشو ما انجرّب.
- `cd … && …` (من bash) بتشتغل كمان بـ PowerShell 5.1.

**مجرّب على اللابتوب:** أعطيناه مهمة: سجل دفع فيه مجموع طلب سالب وقت يكون في خصم. قرأ السجل، لقى السبب (الخصم ما كان
ينقسم على 100)، أعاد إنتاجه (`-900`)، صلّح سطر، ضاف اختبار من حالات السجل، و3 passed، كله بـ 15 خطوة و13.5 دقيقة.
أول ما تختار 🧑‍💻 (أو تفتح مشروع) العقل بيقرأ تعليمات الوضع مسبقاً: أول خطوة صارت 120 ث بدل 321.
لما يقول «خلصت» NewAl بيشغّل اختبارات المشروع (pytest / npm test / cargo / go)، وإذا فشلت بيرجّعه يصلّح (حتى 5 مرات).
بعد ما تنجح، **بيراجع التغييرات** مقابل المهمة (جزء ناقص؟ شي نص خالص؟ print منسي؟) وإذا لقى مشكلة بيرجع يصلّح.

- **📒 الدروس بالمعنى:** طلب بالعربي بيلاقي درس مكتوب بالإنكليزي. العتبة مقاسة بنموذج الفهرسة نفسه
  (المرتبط 0.52–0.73، غير المرتبط لحد 0.43).
بالآخر بتشوف التغييرات (diff) وزر «↩ تراجع» بيرجّع كل الملفات. أوامر الاختبار والبناء بتشتغل لحالها، وأي أمر تاني
(حذف، push...) بيطلب موافقتك. إذا بالمشروع `AGENTS.md` بيمشي على تعليماته.

## 🤖 الوكلاء والنماذج (NewAl منصة)
- **النماذج:** أي نموذج بإعداداته. يا ملف GGUF على جهازك (بيشتغل على llama.cpp تبع NewAl)، يا أي API متوافق مع OpenAI:
  Ollama، LM Studio، جهاز فيه كرت شاشة عالشبكة، OpenRouter، OpenAI…
- **الوكلاء:** الوكيل = نموذج + اسم + دور + اختصاص + أدوات + صلاحية + مين بيقدر يكلّف + طريقة شغله، وكل وكيل ملف Markdown.
  - الجاهزين: القائد، المخطِّط، المبرمج، المختبِر، المراجِع، والمستكشف.
  - بتعدّلهم أو بتزيد تبعك من «🤖 الوكلاء والنماذج»، أو بتحط وكلاء خاصين بمشروع بـ `.newal/agents/`.
- **بوضع 🧑‍💻 القائد بياخد المهمة** وبيكلّف الباقي بـ `delegate`:
  - كل وكيل بيشتغل بسياقه ونموذجه وحدوده (المختبِر بيكتب بملفات الاختبارات بس، والمراجِع قراءة بس) وبيرجّع تقرير.
  - والقائد بيتأكد من التقرير بأدواته.
  - الوكلاء اللي على نفس النموذج بيشاركوا بداية التعليمات.
  - وحالة القائد بتتخزّن عالديسك وقت يشتغل غيره، فلما بيرجع بيقرأ التقرير بس.
- **مجرّب على اللابتوب:** القائد صلّح خلل الخصم، وكلّف المختبِر بالاختبار (8 خطوات، 3 passed)، وبعدين تأكد بنفسه.
  - كلها بـ 14.5 دقيقة.
  - رجعة القائد بعد المختبِر قرأت 292 كلمة بـ 38 ث، بدل 4388 كلمة بـ 215 ث قبل حفظ حالته.
- التصميم الكامل والمراحل: [docs/platform.md](../docs/platform.md).

## 🗂 مهام بالخلفية (متل Codex Cloud)
بتحط كذا مهمة بالدور (من الكمبيوتر أو الهاتف) وبتروح. كل مهمة بتشتغل على **نسخة منفصلة** من المشروع:
git worktree على فرع `newal/<id>` إذا المشروع git (مع التعديلات اللي ما عملتلها commit)، أو نسخة عادية.
ملفاتك ما بتنلمس. لما تخلص: الملفات اللي تغيرت، نتيجة الاختبارات، الـ diff، وأزرار «✅ طبّق» (بينعمل وبيرجع
بـ «↩ تراجع») أو «🗑 ارمِ». بالخلفية بس أوامر الاختبار والبناء بتشتغل، وأي أمر تاني بينرفض لحاله.
المهام بتشتغل وحدة ورا التانية، وكل مهمة إلها محادثة بتقدر تفتحها.
إذا المشروع على GitHub: زر **«📤 افتح Pull Request»** بيعمل commit للفرع وبيرفعه وبيفتح PR فيه الملخص ونتيجة الاختبارات.

## التعلّم من الأغلاط (📒 دفتر الدروس)
لما يغلط بالكود وبعدين يصلّحه، بيكتب قاعدة قصيرة («على ويندوز افتح الملفات بـ utf-8»...). ولما شي بيفشل كل المحاولات،
بيكتب «تجنّب». قبل كل برنامج وقبل كل تصحيح بيقرأ الدروس اللي بتشبه الطلب أو الخطأ. بتشوفها وبتحذفها من 🗂 الذاكرة.

## مشاريع كاملة (عدة ملفات)
للمشاريع الكبيرة بيكتب كل ملف لحال مع مساره (`app/main.py`، `tests/test_app.py`...) وسطر `RUN:`،
NewAl بيكتب الملفات بمجلد تجربة وبيشغّل الاختبارات (pytest) أو الملف الرئيسي، وبالتصحيح بيرجع بس الملفات اللي تغيرت.
لما يشتغل المشروع كامل بينحفظ في `مجلد العمل\projects\`.

## 📱 التحكم من الهاتف
من القائمة ← 📱 الهاتف ← «السماح للهاتف بالدخول» ← امسح رمز QR. بيشتغل بدون نت عبر نقطة اتصال الهاتف، أو كابل USB
(ربط USB)، أو نقطة اتصال الكمبيوتر، أو نفس الواي فاي. كل طلب من الهاتف لازم يحمل المفتاح اللي بالـ QR، و«مفتاح جديد» بيطرد الأجهزة القديمة.

## VS Code
🧩 الإضافات ← «VS Code + Continue» بضغطة: بيثبّت **إضافة NewAl** (أيقونة بالشريط الجانبي) وContinue:
- **▶ اشتغل هلق على هالمشروع:** وضع المشروع على المجلد المفتوح، والخطوات بتنكتب بلوحة «NewAl»، والموافقات بتنطلب
  جوّا VS Code، وزر «↩ تراجع» بالآخر.
- **＋ مهمة بالخلفية:** متل Codex Cloud: لما تخلص بتطلع ملفاتها تحت المهمة، كل ملف بينفتح بعارض الفروقات تبع VS Code
  (مشروعك ↔ اقتراح NewAl)، وبالقائمة: طبّق / ارمِ / افتح Pull Request.
- مجرّبة هون: الإضافة انحمّلت بـ Node مع بديل لـ VS Code واشتغلت على سيرفر NewAl حقيقي (المهام، عارض الفروقات، مهمة جديدة،
  «اشتغل هلق» مع البث والموافقة، والتطبيق). ما انجربت بـ VS Code نفسه.

للمحادثة بـ Continue يدوياً: أضف نموذجاً من نوع OpenAI:
`apiBase: http://127.0.0.1:8766/v1` و `model: newal-auto` (أو `newal-coder`). يبقى NewAl مفتوحاً.

## 🏫 مدرسة Kaggle (التطوير الأسبوعي)
كل أسبوع NewAl بيجمع المهام البرمجية اللي صعبت عليه (فشلت، أو نجحت بعد كذا محاولة، أو قيّمتها 👎) وبيبعتها
لكروت Kaggle المجانية (T4 ×2، 32GB). هناك بيشتغل نفس العقل Qwen3.6-35B-A3B بنسخة أدق (UD-Q4_K_XL) على
llama.cpp مع CUDA: يكتب ← يشغّل ← يحكم ← يصلّح، حتى 6 إصلاحات و3 بدايات جديدة لكل مهمة.
- كل مهمة بتنحل بترجع **درس** بدفتر الدروس و**مثال مجرّب** بيستخدمه بالطلبات المشابهة.
- المهمة اللي بتفشل جلستين بتنشال وبتنكتب «تجنّب».
- لحد 30 ساعة بالأسبوع (قابلة للتعديل)، بجلسات لحد 8.5 ساعة (Kaggle بيوقف الجلسة بعد 9–12 ساعة)،
  وما بيتجاوز الساعات اللي Kaggle معطيك ياها فعلاً. الأسبوع بيبلش السبت 00:00 UTC.
- مهام ويندوز (PowerShell، واجهات رسومية...) ما بتنبعت لأن Kaggle لينكس.
- الأوزان ما بتتغير: تدريب Qwen3.6-35B بيحتاج ~74GB بكرت الشاشة، وKaggle بيعطي 16GB بالكرت.
- الشروط: ربط حساب Kaggle من 🔗 الربط، وتفعيل رقم الهاتف بإعدادات Kaggle (للكروت والنت)، وNewAl مفتوح
  (بيفحص كل 20 دقيقة). البيانات كمان بتتصدّر JSONL من نفس اللوحة.
